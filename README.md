# AI Shorts Maker

내가 직접 기획한 쇼츠 대본 · 상품 사진 · Higgsfield에서 만든 MP4 · 음성 · BGM을 올리면
**1080x1920 / 30fps 세로 쇼츠 MP4**를 자동으로 만들어 주는 Windows 로컬 웹앱입니다.

- 기획과 자료 선택은 사람이 한다. 앱은 **반복되는 편집과 렌더링만** 자동화한다.
- Higgsfield API 연동 없음. 생성한 MP4를 직접 업로드한다.
- Docker / DB / 로그인 / 결제 없음. 데이터는 전부 로컬 JSON + 파일.

---

## 1. 설치

### 1) Python 3.11 이상

- https://www.python.org/downloads/windows/ 에서 설치
  (설치 화면에서 **"Add python.exe to PATH"** 체크 필수)
- 또는 PowerShell에서:

```bash
winget install --id Python.Python.3.12 -e
```

### 2) FFmpeg (필수)

렌더링 엔진입니다. 아래 셋 중 하나로 설치합니다.

```bash
winget install --id Gyan.FFmpeg -e
```

- 또는 https://www.gyan.dev/ffmpeg/builds/ 에서 **full build** zip을 받아
  `C:\ffmpeg`에 풀고 `C:\ffmpeg\bin`을 PATH 환경변수에 추가
- 또는 `ffmpeg.exe`, `ffprobe.exe`를 이 프로젝트의 `bin\` 폴더에 복사

> 설치 직후에는 **새 터미널 창**을 열어야 PATH가 반영됩니다.
> 앱 사이드바에 `FFmpeg 사용 가능 ✅`이 뜨면 정상입니다.

### 3) 실행

`run.bat`을 더블클릭하면 됩니다. 처음 실행할 때만 가상환경(.venv) 생성과
패키지 설치가 진행되고(수 분), 이후에는 바로 브라우저가 열립니다.

```bash
run.bat
```

브라우저가 자동으로 안 열리면 http://localhost:8501 로 접속하세요.
종료는 검은 콘솔 창에서 `Ctrl + C`.

> `run.bat`의 콘솔 메시지는 영어입니다. cmd.exe가 배치 파일을 콘솔 코드페이지로 읽기 때문에
> 한글을 넣으면 일부 환경에서 명령이 깨집니다. 한글 안내는 이 README에 있습니다.

## 2. 사용 순서

### 1. 프로젝트 설정
- 사이드바 `📁 프로젝트`에서 이름을 넣고 **＋ 새로 만들기**
- 해상도 1080x1920, FPS 30 고정
- 목표 길이: 자동(음성 길이 기준) / 15초 / 30초 / 60초
- 프리셋 선택 후 **프리셋 적용** — 컷 길이·효과·색보정·자막·오디오 설정을 한 번에 세팅

### 2. 대본과 음성
- 전체 대본 입력
- MP3/WAV 음성 업로드 → 길이 자동 감지 (목표 길이 `자동`의 기준이 됨)
- 자막 방식 선택
  - **컷별 자막 직접 입력**: 타임라인에서 컷마다 문구 입력
  - **대본 기준 자동 분할**: 대본을 문장 단위로 잘라 전체 길이에 비례 배분
- **대본을 컷 자막으로 자동 배분** 버튼으로 대본을 각 컷에 나눠 넣을 수도 있음

### 3. 미디어 업로드
- 사진 여러 장 / MP4 여러 개 / BGM / 효과음 여러 개
- 업로드한 파일은 `projects\<프로젝트명>\media\` 아래에 저장됨
- 효과음은 시작 시간(초)과 개별 볼륨을 지정

### 4. 타임라인
- 컷 목록에서 `▲ ▼`로 순서 변경, `🗑`로 삭제, `사용` 체크로 포함/제외
- 컷별 노출 시간, 컷 역할(첫 컷 / 일반 / 디테일), 효과, 자막 지정
- **프리셋 길이 규칙 적용**: 첫 컷 1.5초, 일반 2.0초, 디테일 1.0초
- **목표 길이에 맞추기**: 전체 컷 길이를 목표 길이에 비례 배분

효과 (사진 컷에만 적용):
`none` / `slow_zoom_in` / `fast_zoom_in` / `pan_left_to_right` / `pan_right_to_left` / `subtle_shake`

영상 컷은 원본 움직임을 그대로 쓰고, 지정 길이보다 짧으면 **마지막 프레임을 유지**합니다.
컷 사이는 전부 하드컷입니다. (영상 원본 소리는 사용하지 않고 음성/BGM/효과음만 믹싱합니다.)

### 5. 자막 설정
- 흰색 굵은 글씨 + 검은 두꺼운 외곽선이 기본값
- 폰트 / 글자 크기 / 한 줄 최대 글자 수 / 하단 여백(위치) / 정렬 / 색 / 외곽선 두께
- **SRT / ASS 생성** 버튼으로 두 형식 모두 저장 + 다운로드
- 렌더링 시 ASS가 영상에 번인됩니다

### 6. 오디오 설정
- 음성 / BGM / 효과음 볼륨
- **음성이 나올 때 BGM 자동 덕킹** (sidechaincompress, 임계·강도·어택·릴리즈 조절)
- 시작 / 종료 페이드, 마지막 블랙 화면 길이

### 7. 출력
- **미리보기 생성**: 540x960 저화질, 빠르게 확인용
- **최종 렌더링**: 1080x1920 / 30fps / H.264 + AAC / yuv420p / faststart
- 진행률 표시, 완성본 미리보기 + MP4 다운로드
- 프로젝트 JSON 다운로드 / 사이드바에서 JSON 불러오기
- 렌더링 실패 시 원인 요약 + FFmpeg 원본 오류 + 실행 명령 + 로그 파일 경로 표시

## 3. 프리셋: `dark_warning`

경고형 다크톤 쇼츠용 기본 프리셋입니다.

| 항목 | 값 |
|---|---|
| 비율 | 9:16 (1080x1920) |
| 첫 컷 | 1.5초 (권장 1.2~1.8) |
| 일반 컷 | 2.0초 (권장 1.5~2.5) |
| 디테일 컷 | 1.0초 (권장 0.7~1.2) |
| 전환 | 하드컷만 |
| 사진 효과 | slow_zoom_in → pan_left_to_right → fast_zoom_in → pan_right_to_left 순환 |
| 색보정 | 채도 0.72 / 대비 1.18 / 밝기 -0.02 |
| 그레인 | 약한 필름 그레인 (noise 8) |
| 오디오 | 음성 밑 BGM 자동 덕킹 (BGM 0.22) |
| 마지막 | 블랙 화면 0.8초 |
| 자막 | 흰색 굵게 74px + 검은 외곽선 6px, 하단 여백 300px |

`presets\dark_warning.json`을 복사해서 이름만 바꾸면 프리셋을 추가할 수 있습니다.

## 4. 폴더 구조

```
shorts-maker/
├─ app.py                 Streamlit UI (7개 화면)
├─ renderer.py            FFmpeg 렌더 파이프라인
├─ timeline.py            컷 순서 / 길이 / 프리셋 규칙
├─ subtitles.py           대본 분할, SRT / ASS 생성
├─ audio.py               음성·BGM·효과음 믹싱, 덕킹, 페이드
├─ project_manager.py     프로젝트 JSON, 업로드 파일 관리
├─ utils.py               경로, FFmpeg 실행/탐색, 오류 안내
├─ presets/dark_warning.json
├─ projects/<프로젝트명>/  project.json, media/, logs/, .srt, .ass
├─ outputs/               렌더링 결과 MP4
├─ temp/                  렌더링 임시 파일 (작업 후 자동 삭제)
├─ requirements.txt
├─ run.bat
└─ README.md
```

프로젝트는 화면을 조작할 때마다 `projects\<프로젝트명>\project.json`에 **자동 저장**됩니다.

## 5. 렌더링 방식

1. **컷 정규화** — 각 사진/영상을 개별 MP4로 인코딩
   - 원본 비율 유지 → 화면을 채우도록 확대 → 중앙 크롭
   - 사진은 1.5배로 키운 뒤 `zoompan`으로 줌/팬 적용
   - 영상은 `fps` 정규화 + `tpad`로 부족한 길이만큼 마지막 프레임 유지 후 프레임 단위 `trim`
   - 모두 동일한 코덱(H.264) / FPS / `yuv420p` / SAR 1:1 로 통일
2. **concat** — 파라미터가 같으므로 재인코딩 없이 `concat` 디먹서로 연결
3. **자막** — 컷 타이밍(프레임 단위로 양자화)으로 ASS/SRT 생성
4. **최종 인코딩** — ASS 번인 + 페이드 + 오디오 믹싱(`sidechaincompress` → `amix`)
   후 H.264 / AAC / faststart 로 출력

모든 FFmpeg 호출은 `shell=True` 없이 인자 배열로 실행하므로 경로에 **한글과 공백**이 있어도 동작합니다.

## 6. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 사이드바에 `FFmpeg 없음` | FFmpeg 설치 후 **새 터미널**에서 `run.bat` 재실행 |
| `Python 3.11 이상을 찾을 수 없습니다` | Python 재설치 시 "Add python.exe to PATH" 체크 |
| 자막이 네모(□)로 깨짐 | 자막 설정의 폰트를 `Malgun Gothic`으로 지정 (기본값) |
| 렌더링 실패 | 출력 화면의 오류 요약 + `projects\<프로젝트명>\logs\render_*.log` 확인 |
| 업로드가 안 됨 | 파일이 2GB를 넘는지 확인 (`run.bat`의 `--server.maxUploadSize`) |
| 결과가 너무 어둡거나 흐림 | 1번 화면의 채도 / 대비 / 밝기 / 그레인 슬라이더 조정 |

렌더링 결과는 `outputs\` 폴더에 `<프로젝트명>_final_<시각>.mp4` 로 저장됩니다.
